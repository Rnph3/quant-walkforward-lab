**Quant Walk-Forward Lab (Python, Research)**

Built a reproducible chronological backtesting harness using historical normalized equity prices. Implemented moving-average parameter tuning on expanding in-sample windows, non-overlapping OOS evaluation, execution lag, transaction-cost approximation, metrics, plots, and regression tests for future-data leakage. Explicitly documents why these findings are not live trading results or evidence of validated alpha.
